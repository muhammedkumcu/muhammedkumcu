### Selected work

- **[TurkMedSTT](https://github.com/muhammedkumcu/turkmedstt)** — Turkish general and medical speech recognition: two-stage LoRA fine-tuning of Whisper Large V3 with synthetic medical speech, a 20-model ASR benchmark and AcoSemantic evaluation (TÜBİTAK 2209-A). Models, data and demo on [Hugging Face](https://huggingface.co/turkmedstt). Paper at IDAP 2026.
- **[TurkmenFST](https://github.com/aydesma/turkmence-morfolojik-analiz)** — rule-based morphological analysis and generation for Turkmen, with the largest open-source Turkmen lexicon (32,000+ entries). Paper at USBEREIT 2026.
- **[Teke](https://github.com/muhammedkumcu/teke)** — a three-session workflow for Claude Code: you talk to one orchestrator session while code and design run in sessions of their own (Turkish and English).
